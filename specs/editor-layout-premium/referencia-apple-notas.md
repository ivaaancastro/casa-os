# Referencia — Apple Notas (norma de este feat)

> **Norma**: el editor de notas de casa-os se inspira en **Apple Notas**.
> Cualquier decisión de UX/formato dentro de este feat debe acercarse a esta
> referencia salvo que el usuario indique lo contrario.

## Cómo funciona Apple Notas (verificado)

- **La primera línea de la nota ES el título**. Se refleja en el listado.
- Todo el texto (incluido el título) se edita y formatea con la **misma barra
  de formato**; no hay un campo de título aparte.
- **Estilos de párrafo** (menú "Aa" / Format): *Título, Encabezado,
  Subencabezado, Cuerpo* y *Monoespaciado*.
- **Énfasis**: negrita, cursiva, subrayado, tachado.
- **Listas**: viñetas, guiones (dash), numerada y **checklist** (tareas).
  Atajos: `⌘⇧7` bullets, `⌘⇧8` dash, `⌘⇧9` numerada, `⌘⇧L` checklist.
- **Formato enriquecido**: color de texto, **resaltado** con paleta,
  alineación, cita (block quote), super/subíndice, tabla, línea divisoria,
  enlaces e indentación.
- **Secciones plegables** (iOS 18): Título/Encabezado/Subencabezado pliegan el
  contenido inferior. (Nice-to-have, fuera del alcance inicial.)

## Qué implica para casa-os

1. El título se edita como texto enriquecido; se pueden cambiar fuente, tamaño,
   color, etc. sobre él.
2. La barra de formato expone al menos: estilos de párrafo, énfasis, listas
   (viñetas/guiones/numerada/checklist), color, resaltado, alineación, cita,
   código, enlace, tabla, divisoria e indentación.
3. La estética editorial (Inditex) se mantiene: la referencia manda en
   **funcionalidad y flujo**, no en el look (Apple usa iOS/macOS; casa-os usa
   el lenguaje editorial ya aprobado).
